# Weather App
Simple app to fetch weather using https://open-meteo.com/

# Features:
- Home screens: Display current set location information
- Location search: Allow to search location and pin the location as the current location
- Login: Support login with OAuth + Vercel or Firebase. Enable provider for Apple, Google, Support logout/delete account.
- Profile: Display user profile information, allow to edit.
